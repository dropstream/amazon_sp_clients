# amazon_sp_clients

Unofficial Ruby gem for the Amazon Selling Partner API (SP-API), used
internally at Dropstream. It is one gem that wraps many generated API
clients: hand-written core code plus SwaggerCodegen output.

## Layout

- `lib/amazon_sp_clients/` — hand-written core. Edit here.
- `vendor/<api_name>/` — generated client per API. Committed, but never
  edit by hand. It is overwritten on every regeneration.
- `codegen-templates/ruby/` — our modified mustache templates. To change
  generated code, change a template and regenerate.
- `codegen-config.yml` — list of APIs to generate (name + spec path).
- `amzn-models/` — git submodule with Amazon's official specs
  (github.com/amzn/selling-partner-api-models).

## Core files (lib/amazon_sp_clients)

- `../amazon_sp_clients.rb` — entry point. Region and marketplace id
  constants, `configure`, `new_session`, feed upload/download helpers.
- `configuration.rb` — global config (credentials, region, host, sandbox,
  logger). `Configuration.default` is per-thread.
- `session.rb` — auth. Exchanges refresh token for an access token, gets
  STS role credentials, and gets restricted data tokens (RDT) for PII
  calls. `RESTRICTED_OPS` holds the common RDT resource lists.
- `api_client.rb` — Faraday connection used by every generated API class.
  Adds signing, error middleware, tokens, and deserialization.
- `api_response.rb` — wraps the response into `payload` / `errors` /
  `pagination`. Payload is a Hash with symbol keys.
- `api_error.rb`, `uploader.rb` (feed upload + report download),
  `token_exchange_auth.rb` (LWA token request).
- `middlewares/request_signer_v4.rb` — AWS SigV4 signing.
- `middlewares/raise_error.rb` — turns HTTP 4xx/5xx into Faraday errors.
- `sp_*.rb` — autogenerated one-line requires that point into `vendor/`.
  Do not edit; the Rakefile writes them.

## Template changes

Our templates make the generated code use our core instead of the
standard SwaggerCodegen runtime:

- everything lives under the `AmazonSpClients` namespace,
- generated APIs take a `Session` and use `AmazonSpClients::ApiClient`,
- responses default to `AmazonSpClients::ApiResponse`,
- `auth_names` is reused to mark restricted (RDT) operations,
- generated `api_client`, `configuration`, docs and specs are dropped.

## Commands

```sh
bundle exec rspec          # tests
bundle exec rake codegen:generate   # regenerate vendor/ (needs swagger-codegen)
bundle exec rake codegen:clean      # delete vendor/ and sp_*.rb
bin/console                # irb with the gem loaded
```

Regeneration deletes and rewrites all of `vendor/` and all `sp_*.rb`
files. Review that diff carefully before committing.
